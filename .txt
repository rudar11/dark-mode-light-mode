1. Code Ka Asaan Logic (Ghar Ka Example)
theme-context.jsx (Main Inverter / Switchboard):
Context API bas ek main switchboard hai. Iska kaam sirf ye yaad rakhna hai ki abhi light chalu hai (Light mode) ya band hai (Dark mode). Ye switchboard poore ghar se connected hai.

Navbar.jsx (Remote Control):
Tera Navbar ek remote control ki tarah hai. Isme ek button hai (☀️/🌙). Jab tu is button ko dabata hai, toh ye remote seedha Main Switchboard (theme-context) ko signal bhejta hai ki "Bhai, light badal de!"

App.jsx & index.html (Ghar ki Deewarein):
Jaise hi switchboard light badalta hai, tere ghar ki deewaron (HTML ki body) par apne aap naya rang (background color) lag jata hai kyonki wo switchboard se judi hui hain.

Bas itna hi ho raha hai code me! Navbar ne button dabaya, Context ne state change ki, aur HTML ne apna color badal liya.

2. Isme Redux Kyon Nahi Use Kiya?
Ye bohot badhiya sawal hai. Jab hume global state banani thi, toh Context API hi kyon chuna, Redux kyon nahi? Iske 3 main reasons hain:

Faltu ki Mehnat (Over-engineering):
Redux ek bohot badi aur powerful library hai. Isko setup karne ke liye 4-5 alag files banani padti hain (Store, Actions, Reducers). Theme (dark/light) change karna ek bohot hi chhota sa kaam hai. Chhote kaam ke liye Redux lagana waisa hi hai jaise paas wali dukan se maggi laane ke liye udan-khatola (Helicopter) nikalna.

React ke andar free milta hai:
Context API React ke andar pehle se in-built aata hai, uske liye koi extra package download nahi karna padta. Redux ko alag se npm install karna padta hai, jisse website ka size bewajah bada ho jata hai.

Data kitni baar badal raha hai:
Redux wahan kaam aata hai jahan data lagataar badal raha ho. Jaise kisi real-time chat app me jahan har second naye messages aa rahe hain. Wahan Redux performance bacha lega. Par "Dark Mode" din me koi ek ya do baar hi dabayega, isliye Context API iske liye ekdum perfect aur fast hai.

Kyon bhai, ab switchboard aur remote wale example se thoda flow dimag me clear hua ya abhi bhi koi specific file me confusion lag raha hai?
